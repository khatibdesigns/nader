Une balance intelligente qui voit le gaspillage alimentaire.

Phood SolutionsÉtats-Unis2017, 2019Vision par ordinateur

Pour une startup américaine de lutte contre le gaspillage alimentaire, nous avons développé Phood 2.0. Une application Android installée sur une balance tactile industrielle lit le poids et prend une photo ; un classifieur ResNet-20 sur AWS Lambda identifie l’aliment. Une API Node.js transforme chaque relevé en rapports de gaspillage pour les cuisines professionnelles.
