Eine smarte Waage, die Lebensmittelabfall erkennt.

Für Phood Solutions in den USA haben wir Phood 2.0 gebaut: eine Waage, eine Kamera und einen Lebensmittel-Klassifikator, die aus allem, was eine Küche wegwirft, einen Datensatz machen.

Das Problem

Eine Küche kann keinen Abfall reduzieren, den sie nicht misst. Den ganzen Tag landen an jeder Station Lebensmittel im Müll, und niemand hält inne, um aufzuschreiben, was es war, wie viel es wog oder warum es weggeworfen wurde.

Phood 2.0 musste diesen Eintrag genau im Moment der Entsorgung erfassen, fast ohne Mehraufwand für den Koch mit der Pfanne in der Hand.

Was wir gebaut haben

Drei Teile, jeder mit einer Aufgabe.

  • Eine Android-App auf einer industriellen Touch-Waage. Sie las das Gewicht über das serielle Protokoll der Waage aus und machte von jedem Teil ein Foto.
  • Ein Lebensmittel-Klassifikator: ein in Keras gebautes ResNet-20-Modell auf AWS Lambda, das das Lebensmittel auf dem Foto bestimmte.
  • Eine API mit Node.js und Express, die die Welt der Küche abbildete: Organisationen, Standorte, Stationen, Behälter, Lebensmittel-Logs, Abfallberichte, Verlustgründe, Menüs, Bestand und Rollen. Validierung, Authentifizierung und Caching liefen als Middleware vor jeder Route.

So lief es in der Küche.

Fünf Schritte für jedes Teil, die meisten davon automatisch.

  1. 1. WiegenDer Koch stellt die Pfanne oder das Teil auf die Waage. Die App liest das Gewicht über die serielle Verbindung.
  2. 2. FotografierenDie App macht ein Foto des Teils auf der Waage.
  3. 3. KlassifizierenDas Foto geht an den ResNet-20-Klassifikator auf AWS Lambda, der das Lebensmittel bestimmt.
  4. 4. ErfassenDie API speichert einen Eintrag mit Gewicht, Lebensmittel, Station und Verlustgrund.
  5. 5. BerichtenDie Einträge fließen in Abfallberichte für jeden Standort, bereit für die Küchenleitung.

Was wir heute anders machen würden

Das ist unsere Einschätzung im Rückblick. 2017 war ein kleiner, eigens entwickelter Klassifikator in der Cloud die praktikable Wahl. Heute würden wir zuerst zwei Dinge ausprobieren.

Wir würden ein kompaktes Modell direkt auf dem Gerät laufen lassen, damit die Waage weiterarbeitet, wenn das Netz der Küche ausfällt, und ein Foto das Haus nur verlassen muss, wenn es nötig ist.

Für schwierige Fälle würden wir ein modernes Vision-Modell testen, bevor wir ein eigenes trainieren. Es kann ein Gericht benennen, das es nie gesehen hat, und beschreiben, was in einer gemischten Pfanne liegt. Eine feste Liste von Klassen kann das nicht.

Behalten würden wir die Grundform des Systems: ein Handgriff am Abfalleimer, alles andere automatisch, und Berichte, mit denen eine Küchenleitung arbeiten kann.
